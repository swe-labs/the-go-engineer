# Module 16: Portfolio and Interview Readiness

> **Phase:** career | **Status:** draft | **Required:** True | **Pacing:** Moderate

## Goal

Convert verified technical competence into professional software engineering employability.

---

## Architectural Context & Learning Path Flow

Module 16 is positioned to bridge engineering mastery and career transition. While listed at order 16, its activities are designed to run in close coordination with the flagship capstone:

```
[Modules 00 - 15: Engineering Core] ──► [Module 18: Flagship Opslane]
                                                  │ (Produces production artifact)
                                                  ▼
[Module 16: Portfolio & Interview Readiness] ◄────┘
  ├─ Phase A: Core Employability Essentials (Weeks 48–52)
  └─ Phase B: Post-Graduation Career Extensions (Ongoing)
```

- **Flagship Opslane Alignment:** The primary portfolio asset is the Flagship Opslane project built in Module 18. Learners should not fabricate toy demo projects; rather, Module 16 packages the production infrastructure, code reviews, ADRs, and verification suites already created.
- **Continuous Integration:** Key employability habits (writing clear git commit messages, authoring PR reviews, and documenting architectural decisions) are practiced throughout Modules 01–15 and synthesized here.

## Applied Projects & Milestone Assessment

### Capstone Project: `project-portfolio-review-pack`
- **Title:** Portfolio Review Pack (`portfolio-review-pack`)
- **Deliverables:**
  1. Polished GitHub profile with Flagship Opslane and two selected mini-projects as pinned showcases.
  2. Technical write-up and architecture walkthrough answering the Capstone Defense rubric questions.
  3. Tailored engineering resume and LinkedIn profile aligned with target Go backend positions.
- **Verification:** Peer or mentor review evaluating repository readability, README clarity, build verification, and live demo accessibility.

### Milestone Assessment: `assessment-portfolio-interview-readiness-portfolio-review-pack`
- **Format:** Portfolio inspection, behavioral simulation, and live technical defense.
- **Passing Threshold:** 80% passing score on the portfolio review rubric.
