# Module 00 Checkpoint Rubric

This rubric matches the four evaluation dimensions declared in the checkpoint README
and in Lesson 06. Question mapping: Part 1 (Q1-5) -> Repository navigation;
Part 2 (Q6-8) -> Zero-magic contract; Parts 3-4 (Q9-15) -> Workflow and tooling;
Part 5 (Q16-18) -> Roadmap and portfolio planning.

| Dimension | Weight | Meets standard |
|---|---:|---|
| Repository navigation | 30% | Explains the 3 tracks, standard module anatomy, SESE navigation, and where personal code lives; correctly parses a repository path (Q5). |
| Zero-magic contract | 30% | Explains no-hidden-assumption learning in their own words and gives a concrete hidden-magic example plus the correct prerequisite-handling behavior. |
| Workflow and tooling | 25% | Distinguishes lessons, labs, projects, assessments, starters, and solutions; explains `go run` vs `go test` and the 5 Evidence Fields. |
| Roadmap and portfolio planning | 15% | Explains the prerequisite DAG and names concrete portfolio evidence plus a realistic next-two-module plan. |

## Passing standard

Pass: 70% or higher, with no single dimension below 50%.

Retake: revise any dimension below 50% after reviewing the relevant lesson, write one
sentence describing what changed in your understanding, and resubmit.

## Feedback guide

When reviewing your own answers, ask:

- Did I explain using my own words?
- Did I give evidence, not slogans?
- Did I connect file paths to curriculum behavior?
- Did I show how I would use this in the next module?
