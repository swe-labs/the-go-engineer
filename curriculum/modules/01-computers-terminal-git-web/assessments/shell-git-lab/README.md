# Assessment: Shell + Git Lab

## Purpose

This assessment evaluates your understanding of shell commands, Git fundamentals, and web concepts covered in Module 01 — Computers, Terminal, Git, and the Web. It tests both your knowledge recall and your ability to apply concepts in practical scenarios.

## Prerequisites

- [Module 01 Overview](../../README.md) and [Lessons 01–15](../../lessons/01-what-is-a-program/README.md) completed
- [Capstone Project: Shell + Git Lab](../../projects/shell-git-lab/README.md) verified (14/14 checks passing)

## Scope

- Shell commands, exit codes, and pipes (lessons 4-6)
- Git mental model and workflow (lessons 9-13)
- Web preview concepts (lessons 14-15)

Filesystem mechanics from lesson 3 (inodes, CRLF, permissions) are exercised in the capstone project's verification suite rather than in these knowledge questions.

## Time expectation

~30 minutes

## Allowed resources

You may reference your own notes and the module's lesson README files during the assessment. You may NOT search the web, ask AI tools, or discuss answers with others.

## Passing standard

- 18 points total: 10 multiple-choice questions (1 point each) and 4 short-answer questions (2 points each)
- Passing: at least 13 of 18 points (72%)

## Rubric

| Dimension | Approx. weight | Assessed by |
| --- | --- | --- |
| Git mental model and workflow | ~45% (8 pts) | Questions 2, 3, 4, 9, 11, 13 |
| Web preview concepts | ~40% (7 pts) | Questions 6, 7, 8, 12, 14 |
| Shell, exit codes, and pipes | ~15% (3 pts) | Questions 1, 5, 10 |

## Retake policy

You may retake the assessment once after 48 hours. The retake will use different questions covering the same topics. Your highest score will be recorded.
